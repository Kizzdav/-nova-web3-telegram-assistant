# NOVA Web3 Telegram Assistant

## Overview
NOVA is a portfolio demonstration of Telegram community automation built with n8n.

## Features
- Telegram commands: `/start`, `/help`, `/rules`, `/faq` and `/socials`
- AI-powered responses to community questions
- Voice-message transcription workflow
- Conversation memory and configurable AI instructions
- Telegram message responses through automated workflows

## Technology
- n8n Cloud
- Telegram Bot API
- OpenAI model and transcription integration

## Workflow
The exported n8n workflow JSON is provided for technical review. Credentials must be configured separately in your own n8n instance.

## Setup
1. Import the workflow JSON into n8n.
2. Configure your own Telegram and OpenAI credentials.
3. Review the AI instructions and replace demo links with verified project resources.
4. Test the workflow in a private Telegram group before use.

## Security
Never commit API keys, bot tokens, passwords, private keys or other secrets.

## Project status
Portfolio/demo project. NOVA is not presented here as an official token or investment service.
